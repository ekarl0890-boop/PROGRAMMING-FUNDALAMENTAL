DFC10353 Complete Offline Study Hub - GitHub Pages files

Upload index.html, script.js, styles.css, and the assets folder to the root of your GitHub repository. Keep the assets folder structure unchanged.

Enable GitHub Pages in Settings > Pages > Deploy from a branch > main > /(root).

Note: the source PDFs and page images are now separate files so index.html stays below GitHub web-upload size limits. The website requires internet access to load these assets once published; the original single-file version was self-contained offline.
